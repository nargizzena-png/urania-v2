# Как выложить изменения на сайт uraniastudio.eu

Сайт **не** обновляется из GitHub сам. После правок файлы нужно залить на сервер `hive` скриптом `deploy.sh`.

## Что нужно один раз

- Mac, на котором в `~/.ssh/config` есть хост `hive` и ключ `~/.ssh/id_ed25519` (на этом компьютере уже настроено).
- Проверка: в Терминале `ssh hive echo ok` должно напечатать `ok` без запроса пароля.

## Обычный порядок

1. **Сохранить в git** (из папки проекта):
   ```bash
   git add <файлы>
   git commit -m "Что поменяли"
   git push
   ```

2. **Посмотреть, какие файлы менялись** — их и заливаем:
   ```bash
   git show --stat HEAD
   ```

3. **Проверить без заливки** (ничего не меняет на сервере):
   ```bash
   ./deploy.sh --dry-run <метка> <файл1> <файл2>
   ```
   Пример: `./deploy.sh --dry-run instagram includes/footer.php contact.php`

   Для каждого файла скрипт пишет одно из:
   - `ok, se actualizează` — всё в порядке, файл обновится;
   - `deja la zi` — на сервере уже эта версия;
   - `fișier nou` — новый файл;
   - `ATENȚIE: modificat pe server!` — кто-то правил файл прямо на сервере. **Скрипт остановится.** Не заливать, сначала разобраться.

4. **Залить** — та же команда без `--dry-run`:
   ```bash
   ./deploy.sh instagram includes/footer.php contact.php
   ```
   Скрипт сам: делает бэкап старых файлов, заливает новые, ставит права, сверяет результат. В конце должно быть `Gata.`

5. **Открыть сайт** и проверить глазами: https://uraniastudio.eu

## Что заливать не нужно

`PLAN.md`, `VOPROSY-BOSS.md`, `DEPLOY.md`, `deploy.sh`, архивы `.zip`, папка `.claude` — это рабочие файлы, на сайт они не идут.

## Cloudflare (кэш)

- Страницы PHP Cloudflare не кэширует — изменения видны сразу.
- CSS, JS и картинки кэшируются. Если поменяли такой файл, увеличьте версию в ссылке (`style.css?v=3` → `?v=4`) или очистите кэш в Cloudflare: **Caching → Purge Cache**.

## Откат, если что-то сломалось

Каждая заливка сохраняет старые версии на сервере в папку
`/srv/sites/uraniastudio/uraniastudio/backup-<дата>-<метка>/`.
Проще всего вернуть файл из git и залить заново:
```bash
git checkout HEAD~1 -- <файл>
./deploy.sh rollback <файл>
```
